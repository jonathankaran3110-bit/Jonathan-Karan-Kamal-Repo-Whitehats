Researchers at cybersecurity firm XBOW reportedly developed a $250,000 full-chain Google Chrome exploit in just six days, leveraging AI agents powered by OpenAI’s publicly available GPT-5.6 Sol model.
The exploit combined three vulnerabilities to bypass multiple layers of Chrome’s security architecture, potentially allowing attackers to compromise a user's system simply by luring them to a malicious webpage.
Google subsequently confirmed and patched all three vulnerabilities, awarding XBOW its highest $250,000 bounty for a full-chain Chrome exploit. Two of the identified vulnerabilities were classified as high severity.
However, a discrepancy remains in the vulnerability disclosures: CVE-2026-85045, cited for the WebP vulnerability in XBOW’s announcement, is assigned to the V8 vulnerability in both Google’s records and XBOW’s technical analysis. The WebP vulnerability’s separate CVE identifier remains unconfirmed.
